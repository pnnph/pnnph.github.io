# فونت‌ها

**وزیرمتن (Vazirmatn) نسخهٔ ۳۳.۰۰۳** — همان نسخه‌ای که لوگوی مغزینو با آن ساخته شده، تا
سایت و اپ یک خانواده بمانند.

| فایل | وزن | کاربرد |
|---|---|---|
| `Vazirmatn-Regular.woff2` | ۴۰۰ | متن اصلی |
| `Vazirmatn-Medium.woff2` | ۵۰۰ | عنوان کارت‌ها، دکمه‌ها |
| `Vazirmatn-Bold.woff2` | ۷۰۰ | عنوان بخش‌ها، نام در هیرو |

هر فایل حدود ۵۰ کیلوبایت است. فرمت woff2 روی همهٔ مرورگرهای امروزی کار می‌کند.

**مجوز:** SIL Open Font License 1.1 — متن کامل در `OFL.txt`. استفادهٔ تجاری و میزبانی روی سایت
آزاد است؛ فقط فایل مجوز باید همراهشان بماند. منبع: https://github.com/rastikerdar/vazirmatn

## عوض کردن فونت در آینده

فونت فقط در یک جا نام‌گذاری می‌شود: متغیر `--font-fa` در CSS. برای تعویض:

1. فایل‌های woff2 فونت جدید را در همین پوشه بگذار.
2. بلوک‌های `@font-face` را به نام و مسیر جدید تغییر بده.
3. مقدار `--font-fa` را عوض کن.

بقیهٔ سایت دست‌نخورده می‌ماند. برای دیدن نتیجه:

```powershell
node tools/preview/shot.mjs tools/preview/font-test.html --w 900 --h 420
```

این صفحهٔ آزمایشی هر سه وزن را با متن فارسی، ارقام فارسی و متن انگلیسی نشان می‌دهد.

## فونت‌های انگلیسی

**DM Sans** — متن انگلیسی. مجوز SIL OFL 1.1 (فایل `DMSans-LICENSE.txt`).
منبع: پروژهٔ Fontsource / Google Fonts. سه وزن ۴۰۰، ۵۰۰ و ۷۰۰.

**Bluu Next Bold** — تیترهای درشت انگلیسی.
- طراح: Jean-Baptiste Morizot — ناشر: Velvetyne Type Foundry (VTF) — ۲۰۱۴، نسخهٔ ۱.۰۰۴
- این اطلاعات از جدول `name` داخل خود فایل فونت خوانده شده، پس هویتش قطعی است.
- **نکته:** Velvetyne این فونت را از سایتش برداشته و دیگر از منبع رسمی قابل دانلود نیست.
  فایل حاضر به درخواست صاحب سایت از `pouria.design` گرفته شده. Velvetyne فونت‌هایش را
  آزاد (SIL OFL) منتشر می‌کند، ولی متن مجوز همراه این فایل نبود. اگر روزی خواستی خیالت
  کاملاً راحت باشد، یا نسخهٔ رسمی با فایل مجوزش را پیدا کن، یا با طراح تماس بگیر —
  و اگر نشد، `--font-display` در `styles/tokens.css` را به یکی از این‌ها عوض کن:
  Instrument Serif، Fraunces یا Playfair Display (هر سه OFL و آزاد).

## نام‌گذاری فونت‌ها در کد

در `styles/tokens.css` سه متغیر هست و فونت‌ها فقط همان‌جا نام برده می‌شوند:

| متغیر | صفحهٔ فارسی | صفحهٔ انگلیسی |
|---|---|---|
| `--font-body` | Vazirmatn | DM Sans |
| `--font-display` (تیترها) | Vazirmatn | Bluu Next |
| `--font-mono` | فونت سیستم | فونت سیستم |
