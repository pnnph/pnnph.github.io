# آزمون نشان

فایل نشانت را با نام `logo.svg` در همین پوشه بگذار، بعد:

```powershell
node tools/preview/serve.mjs . 4322
```

و در مرورگر باز کن: `http://localhost:4322/tools/logo-test/`

صفحه، نشان را در این حالت‌ها نشان می‌دهد:

1. چهار اندازه — ۹۶، ۴۸، ۲۴ و ۱۶ پیکسل
2. تار شده، برای دیدن سیلوئت
3. روی پوستهٔ روشن
4. داخل دایرهٔ هدر سایت
5. کنار نشان مغزینو، برای سنجیدن هم‌خانوادگی

نشان به‌صورت inline تزریق می‌شود و هر رنگ ثابتی در فایل با رنگ متنِ اطرافش جایگزین می‌شود —
یعنی دقیقاً همان کاری که در خود سایت اتفاق می‌افتد.

`logo.svg` فعلی یک نمونهٔ موقت است تا صفحه خالی نباشد؛ با فایل خودت جایگزینش کن.
