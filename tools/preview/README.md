# ابزار پیش‌نمایش

کروم را بی‌صدا (بدون باز شدن پنجره) اجرا می‌کند، صفحه را باز می‌کند و از آن عکس PNG می‌گیرد.
عکس‌ها در پوشهٔ `.preview/` ذخیره می‌شوند و در گیت ثبت نمی‌شوند.

به هیچ بستهٔ npm نیاز ندارد؛ فقط Node و کروم.

## استفاده

```powershell
node tools/preview/shot.mjs index.html
node tools/preview/shot.mjs index.html --phone          # اندازهٔ موبایل ۳۹۰×۸۴۴
node tools/preview/shot.mjs index.html --full           # کل صفحه، نه فقط بخش اول
node tools/preview/shot.mjs en/index.html --light       # پوستهٔ روشن
node tools/preview/shot.mjs index.html --w 1440 --h 900 --out hero.png
node tools/preview/shot.mjs https://pnnph.github.io/maqzino-privacy/ --full
```

| گزینه | یعنی |
|---|---|
| `--phone` / `--tablet` | اندازهٔ موبایل (۳۹۰×۸۴۴) یا تبلت (۸۳۴×۱۱۱۲)؛ پیش‌فرض دسکتاپ ۱۴۴۰×۹۰۰ |
| `--full` | از کل ارتفاع صفحه عکس می‌گیرد |
| `--light` / `--dark` | پوستهٔ روشن یا تیره را شبیه‌سازی می‌کند (پیش‌فرض تیره) |
| `--w` / `--h` | اندازهٔ دلخواه به پیکسل |
| `--out` | نام فایل خروجی |
| `--wait` | میلی‌ثانیه صبر قبل از عکس‌گرفتن، برای انیمیشن‌ها (پیش‌فرض ۴۰۰) |

اگر صفحه خطای جاوااسکریپت داشته باشد، بعد از عکس در ترمینال چاپ می‌شود — یعنی یک صفحهٔ خراب
بی‌سروصدا از دست نمی‌رود.

## نکته‌ها

- فونت‌ها قبل از عکس‌گرفتن کامل بارگذاری می‌شوند، وگرنه عکس با فونت پیش‌فرض ویندوز گرفته می‌شد.
- مسیر کروم پیش‌فرض `C:/Program Files/Google/Chrome/Application/chrome.exe` است. اگر جای دیگری
  نصب شده، متغیر `CHROME_PATH` را تنظیم کن.
- پوشهٔ `.chrome-profile/` که کنار همین فایل ساخته می‌شود موقتی است و در گیت ثبت نمی‌شود.

این اسکریپت از `tools/brand/cdp.mjs` در مخزن مغزینو گرفته شده و برای صفحه‌های سایت بازنویسی
شده است (پشتیبانی از عکس کل صفحه، پوستهٔ روشن/تیره و اندازه‌های موبایل).
