# فونت‌ها

**وزیرمتن (Vazirmatn) نسخهٔ ۳۳.۰۰۳** — همان نسخه‌ای که لوگوی مغزینو با آن ساخته شده، تا
سایت و اپ یک خانواده بمانند.

| فایل | وزن | کاربرد |
|---|---|---|
| `Vazirmatn-Regular.woff2` | ۴۰۰ | متن اصلی |
| `Vazirmatn-Medium.woff2` | ۵۰۰ | عنوان کارت‌ها، دکمه‌ها |
| `Vazirmatn-Bold.woff2` | ۷۰۰ | عنوان بخش‌ها، نام در هیرو |

هر فایل حدود ۵۰ کیلوبایت است. فرمت woff2 روی همهٔ مرورگرهای امروزی کار می‌کند.

**مجوز:** SIL Open Font License 1.1 — متن کامل در `OFL.txt`. استفادهٔ تجاری و میزبانی روی سایت
آزاد است؛ فقط فایل مجوز باید همراهشان بماند. منبع: https://github.com/rastikerdar/vazirmatn

## عوض کردن فونت در آینده

فونت فقط در یک جا نام‌گذاری می‌شود: متغیر `--font-fa` در CSS. برای تعویض:

1. فایل‌های woff2 فونت جدید را در همین پوشه بگذار.
2. بلوک‌های `@font-face` را به نام و مسیر جدید تغییر بده.
3. مقدار `--font-fa` را عوض کن.

بقیهٔ سایت دست‌نخورده می‌ماند. برای دیدن نتیجه:

```powershell
node tools/preview/shot.mjs tools/preview/font-test.html --w 900 --h 420
```

این صفحهٔ آزمایشی هر سه وزن را با متن فارسی، ارقام فارسی و متن انگلیسی نشان می‌دهد.
